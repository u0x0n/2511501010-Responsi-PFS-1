## Deskripsi
Dashboard admin interaktif untuk mengelola produk toko online dengan fitur CRUD
(tambah, lihat, ubah, hapus) secara client-side. Data disimpan sementara di state React.

## Fitur
- Tabel produk dengan status stok (Aman, Menipis, Habis)
- Tambah, edit, dan hapus produk lewat modal form
- Pencarian nama dan filter kategori
- Kartu ringkasan (total produk, stok menipis, stok habis)
- Tampilan responsif (desktop, tablet, mobile)

## Teknologi
HTML, CSS, Bootstrap 5, JavaScript, jQuery, React 19, Vite

## Cara Menjalankan
1. Pastikan Node.js sudah terpasang
2. Clone repository ini
3. Install dependensi: `npm install`
4. Jalankan: `npm run dev`
5. Buka alamat yang muncul di terminal (biasanya http://localhost:5173)
